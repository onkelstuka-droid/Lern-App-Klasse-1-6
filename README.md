# Lern-App Klasse 1–6

Kindgerechte Lern-App für die Grundschule und Klasse 5–6: Buchstaben, Zahlen, Rechnen, Schreiben mit dem Finger, Bilder benennen mit Spracherkennung und Deutsch – mit Sternen, Stickern, Wiederholen und Fortschritts-Übersicht.

**App öffnen (nach Freischaltung von GitHub Pages):** https://onkelstuka-droid.github.io/Lern-App-Klasse-1-6/

Auf dem Handy in Chrome öffnen → ⋮ → „Zum Startbildschirm hinzufügen“. Funktioniert danach auch offline (Spracherkennung braucht Internet).
